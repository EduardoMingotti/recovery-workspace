# Recovery Workspace V2

Substitua no repositório GitHub Pages os arquivos `index.html`, `styles.css`, `app.js`, `manifest.webmanifest` e `sw.js` pelos arquivos desta pasta.

## Antes
O banco V2 deve estar criado no Supabase.

## Depois de publicar
1. Abra o app e faça login.
2. Na primeira execução, o app cria as oito etapas iniciais e os motivos padrão.
3. Baixe o modelo CSV pelo próprio app.
4. Importe novamente os leads.

A URL e a publishable key continuam sendo as mesmas do projeto Supabase.
